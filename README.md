# 光の板で国旗をつくろう

加法混色(R/G/B の光)・減法混色(C/M/Y のフィルター)の「板」をドラッグして国旗を完成させるパズル。
お手本は出ず、国名だけが出題されます。板は単色で、長方形・円・多角形(三角形や星)があります。ドラッグで移動、ボタンで回転(15°/90°)・拡大縮小(10%刻み)して重ね、混色で旗を作ります。穴(透明部分)があるのは、穴がないと旗にならない板だけです。

## ステージ
- 加法・減法それぞれ27ステージ(5問ずつ・136か国)。板の枚数・穴あき・多角形から自動で難しさを決め、易しい順に並べます。
- ステージ1は位置合わせだけ、2から板の向きがずれ、3から大きさもずれます。5問クリアで次のステージが開きます。
- 進捗は localStorage に保存されます。「全ステージを開放する」で最初から全部遊べます。
- 「フリー出題」では、好きな国旗を選べます。「簡略版も含む197か国」で全データから出題します。

## ポリオミノ版(上級)
「ポリオミノ(上級)」タブでは、長方形だけでできた単純な旗(三色旗など23か国)を、ポリオミノのような形の板で作ります。
- 板はマス目(2×2または3×3の単位)に沿った形で、1つのインクを何枚かの板に分けてあります。同じ色の板は重ねてもよく、重ねないと全体をおおえません。
- 色をつける範囲からはみ出すと色が変わるので、はみ出さないように重ね方を考えます。穴のある板はありません。
- 板は90°回転だけ・拡大縮小なしで、位置はマス目にそろいます。判定は完全一致(一致度99.99%以上)です。
- 板の形は旗とモードごとに固定の乱数で決まり、サーバーでも同じ板で再判定します(ランキングも通常版とは別)。
- 対象は、辺がすべてマス目の線の上にある旗(q=0)のうち、板が14枚以下で、ただの長方形の板が3分の1以下のものです(game-core.js の polyFlags)。
- 5問ずつ5ステージ。進捗は通常のステージとは別に保存されます。

## 起動
    npm install
    npm start        # http://localhost:3000 (PORT 環境変数で変更可)

## 国旗データ(197か国)
public/flags-data.js に、日本が国家承認している195か国(日本・北朝鮮を除く)+日本+北朝鮮の197か国を入れています。
(195か国は、国連加盟国から日本と北朝鮮を除いた191か国+バチカン・コソボ・クック諸島・ニウエ)
各旗に品質 q を付けました。
- q=0:形も色も忠実(縞の太さ・星の向きなどは目安)
- q=4:紋章を円・星・三日月・多角形で近似した旗(ブラジル、カナダ、中国など)
- q=1/2/3:色を6色(白・黒・赤・緑・青・黄)に近似、または細部を省略した旗(実際の旗とは違います)

ステージに出るのは q=0 と q=4 のうち、板が両モードとも10枚以下に収まる136か国です。
星や小さな図形が多い旗(オーストラリア、ニュージーランド、フィリピンなど)は板が多すぎるので外れます。
q=1/2/3 の旗は、フリー出題の「簡略版も含む197か国」でだけ出ます。

## 構成
- server.js … Express(静的配信・ランキングAPI。提出された配置をサーバー側でも再判定)
- public/flags-data.js … 197か国の旗データ(簡易記法)
- public/game-core.js … 旗データ・板の自動生成(ポリオミノ版を含む)・一致判定(サーバーとブラウザで共有)
- public/client.js … 描画(Canvasの lighter / multiply 合成)・ドラッグ操作・UI
- public/index.html, style.css
- public/flags/ … お手本用の国旗SVG(自分で配置)と _list.txt
- check-flags.js … SVGの過不足チェック
- public/vectorize.js … 画像→6色の多角形への変換(ブラウザ・Node共通)
- public/tools/convert.html, convert.js … SVG→板データ(flags-svg.js)の変換ページ
- public/flags-svg.js … 変換結果(初期状態は空)
- data/ranking.json … 実行時に自動作成(Renderの無料枠では再起動で消えます)

## お手本の国旗画像(SVG)
「お手本を3秒表示」は、`public/flags/<国ID>.svg`(例: `jp.svg`)があればその画像を表示します。無い国は従来の図形による近似表示になります。
画像は https://www.sekainokokki.jp/download の「ベクター画像(SVG)」から入手し、ファイル名を国ID(小文字2文字)にして置いてください。
ファイル名と国名の対応は `public/flags/_list.txt`、そろい具合の確認は `node check-flags.js` でできます。
(出典: sekainokokki.jp。非商用・商用とも自由に利用可、元データは Wikimedia Commons)

## 板を本物の国旗に近づける(SVG変換)
1. SVGを `public/flags/<国ID>.svg` に置く(上の節)。
2. `npm start` してブラウザで http://localhost:3000/tools/convert.html を開き、「変換を始める」→「flags-svg.js をダウンロード」。
3. ダウンロードしたファイルで `public/flags-svg.js` を上書きし、ゲームを再読み込み。
SVGがある旗は、図形データのかわりに変換結果(6色の領域=多角形)で板を作ります(品質q=4扱い)。形も色も忠実な旗(q=0)は、変換ページの「q=0も変換する」にチェックを入れたときだけ変換します。
- 色は白・黒・赤・緑・青・黄の6色に寄せます(濃い緑は緑、水色は青など)。
- 縦横比が1.3〜2.1の旗は枠に合わせて引きのばし、それ以外(スイス・ネパール・バチカンなど)は比率を保ち、余白は旗のはしをのばして埋めます。
- 小さい図形(外接長方形が 12×10.8 未満)は、紋章や星の数にかかわらず、同じインクなら1枚の板にまとまります。
- 変換結果が変わると、ステージに出る旗(板10枚以下)とステージの並びが変わります。進捗はステージ番号で保存されているため、ずれることがあります。
- 一致率は変換前の6色画像と多角形の一致度です。98%未満(黄色表示)の旗は見た目を確認してください。
- 変換が重い・細かすぎるときは、変換ページの「細かさ」「消す小ささ」で調整できます。

## 旗の追加
public/flags-data.js に [ID, 国名, 品質q, スペック] を1行足すと、板が自動生成されます。記法はファイル先頭のコメントを参照。
穴が必要なインクの板(例:加法の日本のG・B板)には、自動で穴が付きます。
座標は 30×18 の枠内で、色は W K R G B Y の6色です。
